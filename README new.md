## ✨ About

A fast, single-page portfolio with a bold dark theme and lots of small interactions. No frameworks and no build step: one `index.html` file that runs anywhere.

## 🚀 Features

| | Feature | What it does |
|---|---|---|
| 🎇 | **Particle name** | My name is drawn from hundreds of particles that scatter from the cursor and snap back |
| ⌨️ | **Typing headline** | Cycles through what I build: React interfaces, responsive websites, full-stack apps |
| 🃏 | **3D project cards** | Cards tilt on hover, each with its own animated mini-preview |
| 💻 | **Interactive terminal** | Visitors can type `help`, `skills`, `projects` or `contact` |
| 🌀 | **Motion details** | Skills marquee, magnetic buttons, cursor glow, scroll progress bar, live IST clock |
| 📱 | **Responsive** | Works on phones, tablets and desktops |
| ♿ | **Accessible** | Keyboard focus states, and animations switch off for "reduce motion" users |

## 🛠️ Run Locally

```bash
git clone https://github.com/Mohit2399999/YOUR-REPO.git
cd YOUR-REPO
# just open index.html in your browser — no install needed
```

## ☁️ Deploy

1. Import this repo at **[vercel.com/new](https://vercel.com/new)**
2. Framework preset: **Other** · Build command: *leave empty*
3. Click **Deploy** — every push to `main` redeploys automatically
