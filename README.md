# Priyanshu Suryawanshi — Portfolio

Personal portfolio website: animated particle name, project showcase, and an interactive terminal.

Built with plain HTML, CSS and JavaScript (no build step).

## Run locally
Open `index.html` in a browser.

## Deploy
Import this repo on [Vercel](https://vercel.com/new) — framework preset **Other**, no build command. Every push to `main` redeploys automatically.
